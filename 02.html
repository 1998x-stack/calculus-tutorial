数列的极限

极限不是“最后一项”，而是整个数列后面所有项都能进入任意小的误差范围。ε–N 语言把这件事说得精确。

核心概念逐步推导交互实验自测与边界

数列如何逼近一个目标？

数列是一列按正整数编号的数：a₁,a₂,a₃,…。它可以收敛、发散到无穷，也可能一直振荡。判断极限时，观察的是后面所有项的整体趋势，而不是前几项看起来像什么。

ε–N 定义：把“越来越接近”变成可证明的命题

我们说数列 aₙ 收敛到 L，意思是：不管你要求误差 ε 多小，总能找到一个足够靠后的编号 N，使得从 N 之后，所有项都与 L 相差不到 ε。

∀ε>0,∃N∈ℕ,∀n>N:|an−L|<ε

量词顺序不能颠倒：先给任意 ε，再找到 N；这个 N 可以依赖 ε，但不能依赖某一个特定的 n。最关键的是“对所有 n>N”，它保证了尾部整段都进入误差带。

例：证明 aₙ=1/n → 0

给定任意 ε>0，我们需要 1/n<ε。解这个不等式得到 n>1/ε，因此可以取：

N=⌊1ε⌋+1

当 n>N 时，1/n<1/N<ε。于是证明完成。注意：我们没有要求某一项等于 0；我们证明的是后面所有项都能进入任意小的误差带。

收敛数列的基本性质

  • 唯一性：一个收敛数列不可能有两个不同的极限。
  • 有界性：收敛数列一定有界；反过来不成立，例如 (−1)ⁿ。
  • 保号性：若极限 L>0，则从某一项起，aₙ>0；若 L<0，则最终为负。
  • 四则运算：在相关极限存在且分母极限不为 0 时，可以对和、差、积、商分别取极限。
有界并不意味着收敛。数列 (−1)ⁿ 有界，但始终在两个值之间跳动；单调也不单独保证收敛，必须与有界条件一起使用。

夹逼定理：把目标夹在两条已知序列之间

若从某一项开始，aₙ≤bₙ≤cₙ，且两侧数列都收敛到同一个 L，那么中间数列也只能收敛到 L。

an≤bn≤cn,a→L,c→L⇒b→L

例如 |sin n|≤1，所以：

−1n≤sinnn≤1n→0

因此 sin n / n → 0。这里的关键不是 sin n 本身收敛，而是它被一个趋于 0 的上下界夹住。

单调有界准则：用方向和边界保证收敛

单调递增且有上界的数列必收敛；单调递减且有下界的数列也必收敛。它是证明递推数列收敛的常用工具。

注意“单调”和“有界”缺一不可：1,2,3,… 单调递增但无上界；(−1)ⁿ 有界却不单调。

递推数列示例：aₙ₊₁=√(2+aₙ)

设 a₁=1。先证明 1≤aₙ<2：若 1≤aₙ<2，则 aₙ₊₁=√(2+aₙ)<2；同时 aₙ₊₁≥aₙ，因为在 1≤aₙ≤2 时，2+aₙ≥aₙ²。于是数列递增且被 2 约束，必有极限 L。

对递推式两边取极限，得到：

L=2+L⇒L2−L−2=0⇒L=2

另一个代数根 −1 与数列的非负性矛盾，因此舍去。完整逻辑是：先证明收敛，再对递推式取极限，最后利用范围排除不合理根。
