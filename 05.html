函数的连续性

连续性把函数在一点的值与附近的变化连接起来。它是极限理论走向重要定理的桥梁。

核心概念逐步推导交互实验自测与边界

连续的三个条件：值、极限、相等

函数 f 在 x=a 处连续，需要同时满足三件事：f(a) 有定义；limₓ→ₐ f(x) 存在；这个极限等于 f(a)。少一项都不连续。

1f(a) 有定义2limx→af(x) 存在3limx→af(x)=f(a)

可以把它记成一句话：函数在这个点“接得上”，不仅左右趋势要汇合，而且函数实际取值也要落在汇合的位置。

limx→af(x)=f(a)

连续性的 ε–δ 表达

与极限定义相比，连续性定义不再排除 x=a，因为此时函数值 f(a) 本身也参与比较。

∀ε>0,∃δ>0:|x−a|<δ⇒|f(x)−f(a)|<ε

如果函数在一个区间内每一点都连续，就称它在该区间连续。闭区间端点使用单侧连续：在左端点只从右边逼近，在右端点只从左边逼近。

区间端点：只要求区间内部那一侧

在 [a,b] 上连续，意味着 f 在 (a,b) 每一点连续，并且：

limx→a+f(x)=f(a),limx→b−f(x)=f(b)

这也是为什么“闭区间上连续”并不要求函数在区间外的点有定义。

四类间断点：看左右极限是否存在、是否相等

类型判断特征典型例子
可去间断左右极限存在且相等，但函数值缺失或不等于该极限。sin x / x 在 x=0 处未定义。
跳跃间断左右极限都有限存在，但不相等。符号函数在 0 处。
无穷间断至少一侧函数值无界增大或减小。1/x 在 0 处。
振荡间断函数在任意小邻域内持续振荡，没有有限极限。sin(1/x) 在 0 处。
limx→a−f(x)≠limx→a+f(x)

分类时先分别求左、右极限，再判断函数值。不要只凭图像“看起来断开”就下结论；图像是线索，极限条件才是定义。

三个值得记住的例子

例 1：补上一个点，修复可去间断

令 f(x)=sin x/x（x≠0）。由于 limₓ→₀ sin x/x=1，若再定义 f(0)=1，新的函数就在 0 处连续。

例 2：左右极限不一致，无法修复

f(x)=|x|/x 在 x<0 时为 −1，在 x>0 时为 1。改变 f(0) 的值也无法让左右极限相等，因此不是可去间断。

例 3：无限增长

f(x)=1/x 在 0 两侧分别趋向 −∞ 与 +∞，所以 0 是无穷间断点。注意它在 (0,1) 内每一点仍然连续。

参数如何决定分段函数连续？

考虑：

f(x)={x2x<1ax+bx≥1

在 x=1 处，左极限为 1，函数值与右极限为 a+b。因此连续的充要条件是 a+b=1。不是分别要求 a=1 或 b=1，而是要求这两个参数的和匹配。

  2. 为什么跳跃间断不能通过重新定义 f(a) 修复？

展开参考答案
